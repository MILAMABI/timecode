# Playhead

Трекер времени для креативщиков: видео, фото, дизайн, моушн и 3D, звук. При первом запуске спрашивает, чем ты занимаешься, и подстраивает этапы и программы. Направлений можно выбрать несколько.

| Направление | Программы | Этапы |
|---|---|---|
| Видео | Premiere, Resolve, Final Cut, Media Composer, CapCut, After Effects, Audition, Nuke | Монтаж, Цветкор, Саунд-дизайн, VFX, Рендер |
| Фото | Lightroom, Capture One, Photo Mechanic, Bridge, Photoshop, Luminar, DxO, Topaz, Helicon, Evoto, Retouch4me, Affinity | Отбор, Проявка и цвет, Ретушь, Клинап, Экспорт и сдача |
| Дизайн | Figma, Photoshop, Illustrator, InDesign, Sketch, Affinity, Framer, Canva, Penpot, Bridge | Референсы, Концепт, Макет, Прототип, Подготовка к сдаче |
| Моушн и 3D | After Effects, Cinema 4D, Blender, Houdini, Unreal, Nuke | Моделинг, Анимация, Свет и материалы, Рендер, Композ |
| Звук | Logic Pro, Ableton, FL Studio, Pro Tools, Reaper, Cubase, Audition | Запись, Аранжировка, Сведение, Мастеринг |

Ниже — подробности про видео; для остальных направлений всё работает так же: этап берётся по программе, проект — из заголовка окна.

Трекер времени для монтажёра. Сам пишет время, пока на экране Premiere Pro, DaVinci Resolve, After Effects или Audition, и раскладывает его по этапам и проектам.

- **Premiere Pro**: время идёт как «Монтаж», проект берётся из имени файла `.prproj`. Если крутишь цвет или звук, нажми нужный этап в окне или в меню иконки, и время запишется туда.
- **DaVinci Resolve**: этап определяется по открытой странице. Edit/Cut — «Монтаж», Color — «Цветкор», Fairlight — «Саунд-дизайн», Fusion — «VFX», Deliver — «Рендер».
- **After Effects**: «VFX». **Audition**: «Саунд-дизайн».
- Если 5 минут не трогать мышь и клавиатуру, время не идёт. Короткие отвлечения (до минуты) сессию не рвут.
- Иконка живёт в строке меню на Mac и в трее на Windows. Окно можно закрыть, трекер продолжит работать.
- **Мини-виджет** висит поверх всех окон, в том числе поверх Premiere на весь экран. На нём таймкод, текущий этап и кнопки этапов. Клик по виджету не уводит фокус из монтажки. Виджет можно перетащить мышью, он запомнит место. Включается и выключается в меню иконки или в настройках.
- **Пауза и перерывы.** Круглая кнопка под таймкодом ставит паузу: трекер перестаёт записывать время. Перерыв можно поставить с таймером на 5, 10 или 15 минут: когда время выйдет, придёт уведомление и запись продолжится сама. Перерывы видны в статистике.
- **Фокус-блоки.** Засекаешь 25, 50 или 90 минут работы. Когда блок закончится, придёт уведомление, что пора отдохнуть.
- **Горячие клавиши** работают в любой программе: на Mac **⌃⌥⌘ + цифра**, на Windows **Ctrl+Alt+Shift + цифра**. Цифра — номер этапа, 0 — вернуть авто или остановить таймер, P — пауза.

Данные хранятся только на компьютере, в файле `timecode-data.json`. В настройках есть кнопка «Показать файл с данными».

## Установка

Скачай последнюю версию на странице **Releases** этого репозитория.

### Mac
Какой файл брать: меню  → «Об этом Mac». Если там написан чип **Apple M1/M2/M3/M4**, нужен `Timecode-x.x.x-arm64.dmg`. Если процессор **Intel**, нужен `Timecode-x.x.x-x64.dmg`.

1. Открой .dmg и перетащи Playhead в «Программы».
2. Приложение не подписано сертификатом Apple, поэтому при первом запуске нажми на него **правой кнопкой → Открыть → Открыть**. На новых macOS вместо этого: попробуй открыть, потом **Системные настройки → Конфиденциальность и безопасность**, внизу **«Всё равно открыть»**.
   Если macOS пишет «Приложение повреждено», нажми «Отменить» и выполни в Терминале:
   `xattr -cr /Applications/Playhead.app`
3. Разреши доступ: **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ → Playhead**. Без этого трекер не видит окна программ. В приложении есть кнопка, которая открывает нужный раздел.
4. Когда Playhead в первый раз спросит разрешение управлять «System Events», нажми «Разрешить».

### Windows (`Playhead Setup x.x.x.exe`)
1. Запусти установщик. Если появится «Windows защитил ваш компьютер», нажми **Подробнее → Выполнить в любом случае**.
2. Иконка появится в трее возле часов (может прятаться под стрелкой ^).

### DaVinci Resolve: определение страниц
Нужны две вещи:
- **Python 3.** На Mac он обычно уже есть: если в Терминале команда `python3 --version` показывает версию, всё готово. На Windows — с [python.org](https://www.python.org/downloads/).
- **В Resolve:** Preferences → System → General → External scripting using → **Local**.

В бесплатной версии Resolve внешние скрипты могут не работать. Тогда время в Resolve просто пишется как «Монтаж», а этап можно переключать вручную.

## Как выпустить новую версию

1. Поменяй `version` в `package.json`, например на `1.0.1`.
2. Во вкладке **Releases** нажми **Draft a new release**, в поле тега впиши `v1.0.1` и опубликуй.
3. Через 5–10 минут GitHub соберёт .dmg и .exe и прикрепит их к релизу. Ход сборки видно во вкладке **Actions**.

Собрать без релиза: **Actions → Собрать приложение → Run workflow**. Готовые файлы появятся внизу страницы запуска, в разделе Artifacts.

## Для разработки
```
npm install
npm start      # запустить
npm test       # проверить логику
```

Устройство:
- `src/main.js`: окно, иконка в трее, автотрекинг.
- `src/engine.js`: логика сессий.
- `src/watchers.js`: определение активного окна и связь с Resolve.
- `src/store.js`: хранение данных.
- `renderer/`: интерфейс.
- `helpers/resolve_helper.py`: связь с Resolve.
