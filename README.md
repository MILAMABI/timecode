# Рабочий таймкод

Трекер времени для монтажёра. Сам пишет время, пока на экране Premiere Pro, DaVinci Resolve, After Effects или Audition, и раскладывает его по этапам и проектам.

- **Premiere Pro**: время идёт как «Монтаж», проект берётся из имени файла `.prproj`. Если крутишь цвет или звук, нажми нужный этап в окне или в меню иконки, и время запишется туда.
- **DaVinci Resolve**: этап определяется по открытой странице. Edit/Cut — «Монтаж», Color — «Цветкор», Fairlight — «Саунд-дизайн», Fusion — «VFX», Deliver — «Рендер».
- **After Effects**: «VFX». **Audition**: «Саунд-дизайн».
- Если 5 минут не трогать мышь и клавиатуру, время не идёт. Короткие отвлечения (до минуты) сессию не рвут.
- Иконка живёт в строке меню на Mac и в трее на Windows. Окно можно закрыть, трекер продолжит работать.

Данные хранятся только на компьютере, в файле `timecode-data.json`. В настройках есть кнопка «Показать файл с данными».

## Установка

Скачай последнюю версию на странице **Releases** этого репозитория.

### Mac (`Timecode-x.x.x-universal.dmg`)
1. Открой .dmg и перетащи Timecode в «Программы».
2. Приложение не подписано сертификатом Apple, поэтому при первом запуске нажми на него **правой кнопкой → Открыть → Открыть**.
   Если macOS пишет «Приложение повреждено», выполни в Терминале:
   `xattr -cr /Applications/Timecode.app`
3. Разреши доступ: **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ → Timecode**. Без этого трекер не видит окна программ. В приложении есть кнопка, которая открывает нужный раздел.
4. Когда Timecode в первый раз спросит разрешение управлять «System Events», нажми «Разрешить».

### Windows (`Timecode Setup x.x.x.exe`)
1. Запусти установщик. Если появится «Windows защитил ваш компьютер», нажми **Подробнее → Выполнить в любом случае**.
2. Иконка появится в трее возле часов (может прятаться под стрелкой ^).

### DaVinci Resolve: определение страниц
Нужны две вещи:
- **Python 3.** На Mac он обычно уже есть: если в Терминале команда `python3 --version` показывает версию, всё готово. На Windows — с [python.org](https://www.python.org/downloads/).
- **В Resolve:** Preferences → System → General → External scripting using → **Local**.

В бесплатной версии Resolve внешние скрипты могут не работать. Тогда время в Resolve просто пишется как «Монтаж», а этап можно переключать вручную.

## Как выпустить новую версию

1. Поменяй `version` в `package.json`, например на `1.0.1`.
2. Во вкладке **Releases** нажми **Draft a new release**, в поле тега впиши `v1.0.1` и опубликуй.
3. Через 5–10 минут GitHub соберёт .dmg и .exe и прикрепит их к релизу. Ход сборки видно во вкладке **Actions**.

Собрать без релиза: **Actions → Собрать приложение → Run workflow**. Готовые файлы появятся внизу страницы запуска, в разделе Artifacts.

## Для разработки
```
npm install
npm start      # запустить
npm test       # проверить логику
```

Устройство:
- `src/main.js`: окно, иконка в трее, автотрекинг.
- `src/engine.js`: логика сессий.
- `src/watchers.js`: определение активного окна и связь с Resolve.
- `src/store.js`: хранение данных.
- `renderer/`: интерфейс.
- `helpers/resolve_helper.py`: связь с Resolve.
